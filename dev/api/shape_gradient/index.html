Shape gradients

Analytic gradients of χ² with respect to the shape parameters (radii, inclination, position angle), for joint fits of the surface map and the geometry.

Rotation matrix

FunctionDescription
rotation_matrix(psi, inc, PA)3×3 rotation matrix R(psi, inc, PA), angles in radians; same as rot_vertex
dR_dinc(psi, inc, PA)∂R/∂inc
dR_dPA(psi, inc, PA)∂R/∂PA

xyz = su * R (right multiplication), where su are the scaled unit-sphere vertices.

Shape χ² and gradient

shape_chi2_fg!(grad_θ, grad_xmap, xmap, θ, data, tessels, star_params_base, tepochs; κ=50, verbose=false, parametric_map=false, fit_v0=false, weights=(1,1,1)) returns χ² and fills the gradients with respect to the shape parameters and the map.

  • parametric_map = true recomputes the map from θ (overwriting xmap) and adds its derivative to grad_θ. Surface types 0 and 1 only.
  • fit_v0 = true reads a visibility scale V0 from the last entry of θ (see interferometric_chi2 in Parametric model and AD).
  • weights = (w_V², w_T3amp, w_T3φ) scale each χ² term and its gradients.

The gradient has three parts:

  1. Vertex positions: d(chi2)/d(theta) = sum_p sum_v (d(chi2)/d(proj_west) * d(proj_west)/d(theta) + ...)
  2. Flux normalization: shoelace area derivatives for the flux correction term
  3. Per-tessel weight w = sigmoid(kappa*nz) * ld(nz): d(chi2)/d(theta) += d(chi2)/d(w) * d(w)/d(nz) * d(nz)/d(theta), with d(w)/d(nz) = d(sigmoid)/d(kappa*nz) * kappa * ld + sigmoid * d(ld)/d(nz)

Limb darkening uses ldtype, ld1, ld2 from star_params_base and mu = max(nz, 0), as create_star/compute_ldmap do. The LD coefficients are held fixed: with a free map they are largely degenerate with it. The parametric model fits them.

Shape parameter vector layout

Surface typetheta vectornparams
0 (Sphere)[radius, inclination, PA]3
1 (Ellipsoid)[rx, ry, rz, inclination, PA]5
2 (Rapid Rotator)[rpole, frac_escapevel, inclination, PA]4

Inclination and PA are in degrees. With fit_v0 = true, V0 is appended. Surface type 3 (Roche) has no shape gradient.
