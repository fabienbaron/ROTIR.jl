Plotting

Two plotting layers, each a package extension:

  • PythonPlot (matplotlib): plot2d, plot2d_wireframe, plot2d_allepochs, plot2d_binary, plot3d, plot_rv, plot_mollweide and the draw_* helpers. They use OITOOLS' matplotlib style (set_oiplot_defaults).
  • Makie (any backend): the same plots with a _makie suffix, each returning (fig, ax) (see Makie equivalents).

Plot coordinates: x = East = -proj_west, y = North, in mas; East is to the left.

Decorations

Keywords of plot2d (and plot2d_binary):

KeywordDefaultDescription
compasstrueN/E compass arrows
limbtrueOutline of the projected limb
limb_color"black"Limb colour (also the graticule colour)
limb_linewidth0.8Limb width
graticulesfalseLatitude/longitude lines on the surface
rotation_axisfalseRotation axis, dashed, with an arrow at the north pole
rotation_arrowfalseArrow around the north pole showing the sense of rotation
inclination, position_angleNaNOrientation for the decorations (degrees); from the mesh if NaN
star_paramsnothingStar parameters, for the closed-form surface shape of the graticules
graticule_kwargs(;)Passed to draw_graticules (see below)

The orientation comes from inclination/position_angle when given, otherwise from the mesh, which includes the rotation phase. star_params gives the surface shape only.

Graticules use a closed-form shape for a sphere, triaxial ellipsoid or rapid rotator when star_params is given. Otherwise, including for a Roche lobe (surface_type = 3), the shape is interpolated from the mesh's r(θ, φ). Curves end at the limb, where the mesh normal turns away from the observer.

The limb outline keeps the disk visible when the surface maps to the pale end of the colormap on a white background.

Binary sky-plane

FunctionDescription
plot2d_binary(tmap1, tmap2, star1, star2, bparams, tepoch; kwargs...)Both components at their orbital positions, nearer one in front; returns (fig, ax)

tepoch is in the time system of bparams.T0. plot2d_binary takes the decoration keywords of plot2d, intensity, intensity_model, band, plotmesh, colormap, background, figtitle, pad (default 1.0), and:

KeywordDefaultDescription
star_params1, star_params2nothingStar parameters for each component's graticules
inclination1, position_angle1NaNOrientation of star 1 for the decorations
inclination2, position_angle2NaNOrientation of star 2 for the decorations
vmin, vmaxnothingFix the shared colour scale
colorbar_ontrueDraw the colour bar
axnothingDraw into an existing axes
axis_maxnothingPlot half-width (mas)
graticule_kwargs(;)Graticule style, both components
`inclination1` / `position_angle1`

create_binary_geometry orients both components from the orbital elements (i, Ω, ω) through binary_frame; a component's own inclination and position_angle are not used. Passing them here draws the decorations for a different orientation (over 100° apart for a Spica-like system). Leave them at NaN to use the mesh orientation.

Radial velocity

FunctionDescription
plot_rv(bparams; K1, K2, γ=0.0, rv_data1=nothing, rv_data2=nothing, figtitle="Radial Velocities")Model RV curves against orbital phase; returns (fig, ax)

rv_data1 / rv_data2 are N×3 matrices [time, RV, error] (km/s), with time in the system of bparams.T0. N×2 matrices are drawn without error bars.

Controlling the furniture

KeywordDefaultDescription
graticuletrueDraw meridians and parallels
lon_spacing20 (HEALPix), 30 (lat/long)Meridian spacing (degrees)
lat_spacing15 (HEALPix), 30 (lat/long)Parallel spacing (degrees); must divide 90
labelstrueDegree labels
grid_style"-"Graticule linestyle, e.g. ":"

axis_linesfalseDraw the equator and central meridian as solid lines

colorbar_ticks7Number of colour bar ticks

A lat_spacing that does not divide 90 raises an error: matplotlib labels the parallels in multiples of the spacing, so other values put the labels on the wrong lines.

The settings below match healpy's mollview (dotted graticule, solid equator and central meridian, no degree labels, colour bar with its two end values). demos/zetand_render_map.jl uses them.

plot_mollweide(map, star; vmin = 0.8025, vmax = 0.9977, colormap = "gist_heat",
               title = "ζ And 2019A",
               labels = false, lon_color = "black", lat_color = "black",
               grid_style = ":", grid_alpha = 0.9,
               lon_spacing = 30, lat_spacing = 30, axis_lines = true,
               colorbar_ticks = 2, colorbar_label = "")

Makie equivalents

Available once a Makie backend is loaded (CairoMakie for files, GLMakie for windows). Each returns (fig, ax); plot2d_allepochs_makie returns fig.

FunctionMatplotlib counterpart
plot2d_makie(tmap, star; ...)plot2d; adds colorbar and figsize
plot2d_wireframe_makie(star; ...)plot2d_wireframe (see note below)
plot2d_allepochs_makie(tmap, stars; ...)plot2d_allepochs; adds pad, panelsize
plot2d_binary_makie(tmap1, tmap2, star1, star2, bparams, tepoch; ...)plot2d_binary
plot3d_makie(tmap, star; ...)plot3d; rotatable, orthographic, axistype = :lscene or :axis3
plot3d_binary_makie(tmap1, tmap2, star1, star2, bparams, tepoch; ...)both components in 3D, with the relative orbit (orbit = true)
plot_rv_makie(bparams; K1, K2, ...)plot_rv
plot_mollweide_makie(tmap, star; ...)plot_mollweide
draw_compass_makie!, draw_limb_makie!, draw_graticules_makie!, draw_rotation_axis_makie!, draw_rotation_arrow_makie!, add_tessel_collection_makie!the draw_* helpers

plot_mollweide_makie takes visible_pixels, mask_unobserved, bad_color, vmin, vmax, colormap, figtitle, incl, lon_color, lat_color, labels, colorbar, nlon/nlat (resampling grid, default 720×360) and figsize; not the styling keywords of Controlling the furniture.

`hidden` in the wireframe plots

plot2d_wireframe(star; hidden = true) draws the far side; plot2d_wireframe_makie(star; hidden = true) does not, and draws it with hidden = false.
