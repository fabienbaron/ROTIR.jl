Star parameters

Parameters are a NamedTuple; the required fields depend on surface_type. The binary code builds the same fields with starparameters(); see Orbits.

Common fields

FieldTypeDescription
surface_typeInt0 = sphere, 1 = ellipsoid, 2 = rapid rotator, 3 = Roche
tpoleRealPolar temperature (K)
ldtypeIntLimb-darkening law: 0 = none, 1 = linear, 2 = quadratic, 3 = power law (Hestroffer), 4 = Claret
ld1, ld2RealLimb-darkening coefficients (ld3, ld4 for ldtype = 4)
inclinationRealSpin-axis inclination (degrees)
position_angleRealSpin-axis position angle (degrees)
rotation_periodRealDays
t0RealRotation phase zero, in the epochs' units (optional, default 0)

Sphere (surface_type = 0)

FieldDescription
radiusAngular radius (mas)

Ellipsoid (surface_type = 1)

FieldDescription
radius_x, radius_y, radius_zSemi-axes (mas)
betaGravity-darkening exponent

Rapid rotator (surface_type = 2)

FieldDescription
rpolePolar radius (mas)
frac_escapevelΩ/Ω_crit, from 0 to 1
betaGravity-darkening exponent
gravity_law1 or :vonzeipel (default), 2 or :elr (Espinosa Lara & Rieutord 2011); optional
B_rotDifferential rotation coefficient

Roche lobe (surface_type = 3)

FieldDescription
rpolePolar radius (mas)
betaGravity-darkening exponent
qMass ratio Mcompanion/Mself: M₂/M₁ on the primary, M₁/M₂ on the secondary
fillout_factor_primary, fillout_factor_secondaryFill-out factor; -1 uses rpole
POrbital period (days)
aSemi-major axis (mas)
eEccentricity
T0Time of periastron, in the epochs' time system
dPPeriod derivative (days/day); required by compute_separation
i, Ω, ωOrbital inclination, ascending node, argument of periapsis (degrees); used by binary_frame
dDistance (pc), for physical-unit conversions

create_star orients a Roche component with inclination, position_angle and rotation_period, like a single star; create_binary_star orients it from the orbit. Ω and ω are Unicode field names.

The Roche potentials, gravities, volumes and fill-out conversions (compute_potential_*, compute_gravity_*, roche_volume, fillout_to_rpole, rpole_to_fillout) take the binary mass ratio M₂/M₁ for both components, with secondary = true for the secondary. roche_q(params; secondary) converts a component's q to it; update_roche_radii, rl1, max_rpole, temperature_map_vonZeipel_roche_single, roche_mesh_volume and roche_omega_for_volume apply it themselves.

Roche lobe functions

Radii are in units of the semi-major axis a unless noted.

FunctionDescription
update_roche_radii(tessels, params, D; use_fillout_factor, secondary, omega)Radii (mas) at all vertices from the surface potential

solve_R_L1(r0, D, q, async_ratio, potential_function; secondary)Distance to the L1 point (Newton)
compute_gravity_primary(r, θ, ϕ, D, q, async_ratio)Magnitude of the local gravity, primary
